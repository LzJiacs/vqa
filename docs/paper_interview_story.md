# 可验证多模态文档问答：论文与面试叙事模板

## 一句话定位
我们做的是“证据驱动 + 可拒答”的多模态文档问答系统，目标是降低传统 VQA 幻觉并提升可追溯性。

## 方法链路
1. `PaddleOCR + 布局分块`：将文档图像转成结构化区域（region）。
2. `BGE 稠密检索`：从 region 中召回 top-k 候选证据。
3. `Cross-Encoder 重排`：对候选证据做查询相关性重排。
4. `Qwen2.5-VL 证据感知推理`：仅基于重排证据和图像回答。
5. `可回答性判定 + 阈值拒答`：无充分证据时输出拒答，抑制幻觉。

## 关键创新点（可写论文贡献）
- 提出文档 VQA 的“检索-重排-推理-拒答”统一框架，支持显式证据链。
- 通过 answerability 阈值校准机制，把“是否回答”作为一等目标优化。
- 在 DocQA / ChartQA 上验证：相较无证据 baseline，可靠性与可解释性显著提升。

## 面试可讲的工程亮点
- 在单卡 RTX 4090 上可复现实验（给出固定参数、脚本化 pipeline、日志可追踪）。
- 构建了可扩展的数据转换层（DocVQA / ChartQA / 自有教案）。
- 设计了自动化评测与结果汇总脚本，支持快速迭代与消融。

## 建议实验（投 EMNLP / NeurIPS）
- 主实验：DocQA、ChartQA（Exact / Relaxed / 拒答准确率 / 幻觉率）。
- 消融实验：
  - 去掉重排器
  - 去掉拒答机制
  - 不同检索 top-k
  - 不同阈值策略（固定阈值 vs 校准阈值）
- 误差分析：数值题、跨区域证据题、OCR 噪声题。
